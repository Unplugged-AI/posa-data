# POSA US Offline Data 2026-08-07.1

The first public POSA data release includes combined offline map and point-of-interest packages for all 50 U.S. states and the District of Columbia.

Each ZIP contains the Mapsforge map file or files, the Mapsforge POI database, and a JSON manifest with source information and SHA-256 checksums.

## Important

Map and POI artifacts in this build came from separate provider snapshots and are not guaranteed to represent the same OpenStreetMap snapshot.

Mapped data does not prove current access, conditions, availability, potability, operating hours, or route safety. Verify critical information through authoritative local sources whenever possible.
